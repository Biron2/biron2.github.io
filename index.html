About me

Biron is my nickname. The main thing I do is games in Unity with C#.

I build both offline games — saves, levels, character, inventory — and online games with multiplayer, player sync and leaderboards. A single project can build for both phone and PC.

I also build mobile apps: native ones in Java with Android Studio, and cross-platform ones in Dart with Flutter inside Visual Studio Code — one codebase for Android and iOS.

I do build websites with HTML and CSS, but I'm not a strong web developer — mostly simple sites and landing pages.

What I don't do

Online stores, portals, CMS work and non-standard backends aren't for me — that's not my area. I'd rather say so upfront than waste your time.
