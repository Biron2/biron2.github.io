About me

Unity is my main thing

Biron is my nickname — that's what people usually call me. What I mainly do is games in Unity with C#. That's the area I'm strongest in: I take a game from the idea and the prototype all the way to a finished build for PC, Android and iOS.

I build both offline games — saves, levels, character, inventory — and online games with multiplayer, player sync and leaderboards. A single project can build for both phone and PC.

Besides Unity I build mobile apps: native ones in Java with Android Studio, and cross-platform ones in Dart with Flutter inside Visual Studio Code — one codebase for Android and iOS.

I do build websites with HTML and CSS, but let me be honest: I'm not a strong web developer. I mainly take on simple sites and landing pages.

Honest note about complex web work

If the task is complex — an online store, a portal, a CMS, a non-standard backend — tell me upfront. I'll warn you in advance: I'll only take it together with a partner or hand it over to a dedicated web developer, so you don't waste time and money.
